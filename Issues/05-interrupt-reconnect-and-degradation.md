# 新问题打断、断线温和重连与不可用降级

类型：AFK

状态：已完成（2026-06-28）

覆盖用户故事：5、15、16、17、32、35

## What to build

补齐游客连续问答和数字人异常时的稳定行为。任何新的有效文字或语音问题都先中止当前 TTS 与 LiteAvatar 播放，再开始新问题；被中止的旧回答不恢复、不重播。avatar service 初始化失败或会话中途断开时，页面降级为纯文字问答并显示“未连接”，随后在后台温和尝试恢复。

重连只恢复后续问题的播报能力，不补播断线期间或恢复前已经完成的回答。

## Acceptance criteria

- [ ] 提交新的有效文字问题时，当前数字人口播会立即收到中止指令。
- [ ] 提交新的有效语音识别结果时，当前数字人口播同样会立即收到中止指令。
- [ ] 被中止问题剩余的语音和视频不会在新问题期间继续播放，也不会稍后恢复。
- [ ] 连续快速提问时，仅最新问题可以继续驱动新的播报，不出现旧流串入新流。
- [ ] avatar service 中途断开后，左侧状态转为“未连接”，右侧 A5 问答与来源卡保持可用。
- [ ] 前端在后台采用有上限、不过度频繁的方式尝试恢复连接，不阻塞用户操作。
- [ ] 重连成功后复用或重建一个有效 session，后续新问题可恢复播报。
- [ ] 断线期间已经完成或错过的回答不排队、不补播。
- [ ] 重连和 session 替换不会遗留旧媒体轨道、定时器或重复事件监听。
- [ ] 有行为级测试或可重复联调验证覆盖提问打断、快速连续提问、播报中断线、重连成功和持续不可用。
