# 麦克风半双工录音、ASR 回填与自动发问

类型：AFK

状态：已完成（2026-06-28）

覆盖用户故事：7、8、9、10、20、30、34

## What to build

在 `/guide` 现有聊天输入区保留麦克风按钮，并将语音输入改为由 avatar bridge 编排的半双工流程：游客点击开始录音，再次点击结束；OpenAvatarChat 侧完成 ASR 后，将识别文本作为普通用户消息写入聊天记录，并自动走与文字输入完全相同的 A5 流式问答链路。

录音、识别和发问共享左侧状态机。空结果或识别失败只显示轻量提示，不创建用户消息，也不调用 A5。

## Acceptance criteria

- [ ] 麦克风按钮保留在聊天输入框区域，文字输入仍可独立使用。
- [ ] 第一次点击开始录音并进入“正在聆听”，第二次点击结束录音并进入“识别中”。
- [ ] 录音期间不会并行开启第二段录音，页面能明确反映当前录音状态。
- [ ] ASR 由 avatar service/OpenAvatarChat 链路完成，前端通过 A5 专用 bridge 接收最终识别文本。
- [ ] 有效识别文本作为普通用户消息显示在右侧聊天记录中。
- [ ] 有效识别文本自动调用与文字输入相同的 A5 流式问答链路，并进入“思考中”。
- [ ] ASR 返回空文本、无有效语音或识别失败时，只显示简短中文提示，不新增用户消息、不调用 A5。
- [ ] 用户拒绝麦克风权限或浏览器无法录音时，文字问答仍正常可用。
- [ ] 录音媒体资源在结束、取消、页面离开和异常时均被释放。
- [ ] 有行为级测试或可重复联调验证覆盖成功识别、空结果、识别失败和权限拒绝。
