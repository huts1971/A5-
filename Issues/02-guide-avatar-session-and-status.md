# 打通 `/guide` 单会话初始化、健康检查与左侧状态层

类型：AFK

状态：已完成（2026-06-28）

覆盖用户故事：11、13、14、16、17、21、31

## What to build

让 `/guide` 页面在不大幅改变现有聊天布局的情况下接入 avatar service：进入页面时创建唯一 avatar session，离开或刷新时销毁，并在左侧展示 LiteAvatar 视频区域和一层简短中文状态。页面不等待数字人初始化即可使用文字问答。

状态层只在左侧数字人区域下方显示，连接前使用“准备中”或“未连接”；连接成功后支持“正在聆听”“识别中”“思考中”“播报中”。右侧聊天区不重复展示这些状态。

## Acceptance criteria

- [ ] 进入 `/guide` 后立即渲染聊天界面和左侧数字人区域，不因 avatar service 冷启动阻塞页面。
- [ ] 每个 `/guide` 页面生命周期最多创建一个 avatar session。
- [ ] 离开页面或刷新时会请求销毁当前 session，并清理前端连接与媒体资源。
- [ ] 左侧区域能承载 LiteAvatar 音视频，尺寸允许按内容调整且桌面页面无明显遮挡、白屏或水平溢出。
- [ ] 状态层位于左侧数字人区域下方，只显示约定的短中文状态。
- [ ] 未连接时显示“未连接”，初始化中显示“准备中”。
- [ ] 连接后可接收并显示“正在聆听”“识别中”“思考中”“播报中”，且右侧聊天区不重复铺开。
- [ ] avatar service 不可用或 session 尚未 ready 时，现有文字提问、流式回答和来源卡仍正常。
- [ ] 欢迎文字保留，但进入页面时不自动触发欢迎语音。
- [ ] 前端构建通过，并有行为级验证覆盖 session 单例、页面卸载清理和状态映射。
