# 数据与评测接口

## Chunk

`Chunk` 包含 id、document_id、parent_id、title、section、text、map_id、spot_id、source_url、source_type、pages、approved、metadata。

正文按结构和句子边界切块；表格按行展开并携带列名。corpus_id 对应批准语料的内容哈希，Milvus 集合与评估标注使用相同快照。

## 训练样本

`TrainingExample` 保存类别、来源文档、chunk ID、messages、tools、split、provenance、approved、reviewer。教师生成的问题与答案配合逐查询召回观察组成监督轨迹；引用必须覆盖于观察。

文档哈希确定分集。审核通过的样本导出到 train/dev/test，训练使用 Qwen chat template 和 assistant loss mask。

## 预测与评分

| 记录 | 字段 |
| --- | --- |
| 检索标注 | id、question、scope、corpus_id、relevant_chunk_ids |
| 问答输入 | id、question、scope |
| 问答预测 | id、user_input、response、retrieved_contexts、status、error、trace |
| 检索汇总 | Recall/Hit/MRR/nDCG@5、模式、样本量、错误数 |
| RAGAS 汇总 | faithfulness、answer_relevancy 的均值、有效数、失败数 |
| LoCoMo 汇总 | Single Hop / Multi Hop F1、覆盖率、缺失题 |

LoCoMo 使用独立情节记忆插件，读取 conversation 构建记忆；评分以 QA 的标准答案计算 token F1，范围为 0–100。Single Hop 对应类别 4，Multi Hop 对应类别 1。

命令、指标定义和产物路径见 [训练与评估](../../../docs/training-evaluation.md)；结果见 [指标记录](../../../docs/results.md)。
